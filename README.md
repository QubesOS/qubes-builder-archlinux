# Qubes Builder Arch Linux

Most of this repository is obsolete. It is the Arch Linux plugin for the legacy
[qubes-builder](https://github.com/QubesOS/qubes-builder), which is no longer
supported.

The `template_archlinux` directory is still used.
[qubes-builderv2](https://github.com/QubesOS/qubes-builderv2) runs its scripts
to build the Arch Linux template.
